# Quickstart: Image Folder Viewer

## Prerequisites
- Node.js 20 or newer
- A modern web browser with folder selection support

## Setup
1. Install dependencies with `npm install`.
2. Start the Vite development server with `npm run dev`.
3. Open the local preview URL in the browser.

## Validation Steps
1. Use the folder picker to choose a directory containing JPEG, PNG, or WebP files.
2. Confirm that the first supported image appears and that the UI shows the current position in the set.
3. Use the previous and next controls to move between images.
4. Verify that empty folders and unreadable folders show the expected message.
5. Toggle the theme and confirm that the UI remains readable in both light and dark modes.
